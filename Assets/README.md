# App artwork

`AppIcon.png` is the source artwork, generated with the built-in OpenAI image-generation tool. The build script creates the macOS ICNS sizes and the local PNG icons used by the phone page; no runtime generation or external image requests are needed. The source is included under this repository's MIT licence.

The menu-bar symbol remains a monochrome system symbol for legibility in light and dark menu bars.

## Generation prompt

Use case: logo-brand. Asset type: finished macOS application icon for 'Sofa Remote', a friendly free iPhone mouse-and-keyboard remote for Mac. Create ONE square 1024x1024 production icon, not a mockup or contact sheet. Subject: a beautifully simple soft cobalt-blue two-seat sofa with a large crisp warm-white computer cursor arrow resting diagonally over its right seat; the cursor is instantly legible at small sizes. A subtle sky-blue top light and restrained soft dimensional shading make the sofa tactile but keep the silhouette bold. The sofa and cursor sit on a smooth deep midnight-blue rounded-square macOS icon tile, with a very subtle blue gradient and precise soft corners. Centered, generous clean margins; tile occupies about 88 percent of canvas so edges have a genuinely transparent exterior. No text, no letters, no phone, no remote-control handset, no screen, no Wi-Fi arcs, no extra symbols, no branding from existing apps, no glossy plastic clutter, no watermark. Premium calm native macOS aesthetic; highly readable as a small app icon. Transparent background outside the rounded-square tile.
