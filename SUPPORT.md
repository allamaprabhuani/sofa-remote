# Help and contact

Start with [Setup and troubleshooting](docs/SETUP.md) and [Known issues](KNOWN_ISSUES.md).

- **Bugs:** [Open a bug report](https://github.com/allamaprabhuani/sofa-remote/issues/new?template=bug_report.yml). Include exact steps, expected/actual behaviour and versions. Try an empty/disposable window rather than private content.
- **Ideas:** [Suggest a feature](https://github.com/allamaprabhuani/sofa-remote/issues/new?template=feature_request.yml).
- **Questions and developer contact:** [GitHub Discussions](https://github.com/allamaprabhuani/sofa-remote/discussions). Maintainer: [Allamaprabhu Ani](https://github.com/allamaprabhuani). These are public channels and require a GitHub account to post.
- **Security vulnerabilities:** [Report privately](https://github.com/allamaprabhuani/sofa-remote/security/advisories/new), following [SECURITY.md](SECURITY.md). Do not post exploit details in public issues.

In **About & Help**, review the diagnostic summary, then explicitly choose Copy if you want to include it. It contains allowlisted app/build, operating system, browser (on the phone), permission and sharing status only. It excludes input text, credentials, network addresses, device names, personal URLs and screenshots. Check anything else you add before posting. Nothing is sent to the developer automatically.

Sofa Remote is maintained as a free open-source project. Support is best effort, with no response-time guarantee. The current beta is the supported testing line; update before reporting a fixed issue. A clear small reproduction helps more than large logs. Screenshots of personal desktops, app-data files and pairing links should not be attached.
